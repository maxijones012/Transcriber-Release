# Transcribe — Releases oficiales

Repositorio público de distribución de **Transcribe para Android**.

## Descargar

La versión pública más reciente estará siempre en:

**Releases → Latest**

Archivo oficial:

`Transcribe.apk`

También se publica:

`Transcribe.apk.sha256`

para verificar la integridad de la descarga.

## Instalación

1. Descargá `Transcribe.apk` desde la sección **Releases**.
2. Abrí el archivo desde Descargas.
3. Si Android lo solicita, autorizá temporalmente la instalación desde esa fuente.
4. Tocá **Instalar**.
5. Las siguientes versiones podrán instalarse como actualización mientras conserven la misma firma.

## Monetización

La build pública usa la configuración de producción de Google AdMob. Las builds de desarrollo/beta usan inventario de prueba de Google para evitar clics o impresiones inválidas durante el desarrollo.

## Privacidad

Los modos locales procesan audio y texto en el dispositivo.

Si en el futuro se habilita **Turbo online**, la app lo indicará expresamente antes de enviar temporalmente la pista de audio.

## Importante

Este repositorio contiene únicamente archivos de distribución y notas de versión. El código fuente principal se mantiene separado.
